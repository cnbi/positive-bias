# positive-bias

This is a project to investigate the consequences of ignoring the nested structure of data, with a demonstration using empirical data as well as a small-scale simulation study.
The authors are Jinyu Chen, Alfons Edmar, Camila Barragan Ibanez, Ulrich Lösener, and J. Leon Kenemans.

This repository contains the code for the simulation study.

For questions and inquiries, please contact the first author.
